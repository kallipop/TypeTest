# Type Speed Test

A simple typing speed test built with HTML, CSS and Javascript

The user types a randomly selected paragraph while the timer runs and receives results at the end of the test

## Features

- 15, 30, 60, 120 seconds tests
- Random paragraphs
- Different paragraph difficulty based on the test duration
- Real-time timer
- Correct and incorrect character highlighting
- Mistake counter
- WPM calculation
- Accuracy calculation

## Technologies

- HTML
- CSS
- Javascript
